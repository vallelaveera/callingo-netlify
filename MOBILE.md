# Callingo — Mobile (Android) Build

This guide takes you from cloned repo to a working APK on a real Android device.
No Play Store submission, no production signing — just a local debug build.

There are two halves:
1. **Backend** — a Cloudflare Worker that proxies Claude API calls (replaces Netlify Functions).
2. **App** — the existing web app wrapped with Capacitor as a native Android app.

---

## Part 1 — Cloudflare Worker (backend)

The mobile app must call an absolute https URL. Run this once.

```bash
npm install -g wrangler
wrangler login          # opens a browser

cd cloudflare
wrangler secret put ANTHROPIC_API_KEY   # paste your key
wrangler deploy
```

Wrangler prints a URL like `https://callingo-claude.<your-subdomain>.workers.dev`.
Copy that URL.

**Test it:**
```bash
curl -X POST https://callingo-claude.<your-subdomain>.workers.dev \
  -H "Content-Type: application/json" \
  -d '{"messages":[{"role":"user","content":"say hi in 3 words"}]}'
```

You should see a JSON response with Claude's reply.

---

## Part 2 — Point the app at your Worker

Edit `public/config.js` and replace the placeholder URL:

```js
window.APP_CONFIG = {
  apiUrl: 'https://callingo-claude.<your-subdomain>.workers.dev',
};
```

Then sync into the Android project:

```bash
npx cap sync android
```

Re-run `npx cap sync android` any time you change anything in `public/`.

---

## Part 3 — Build the Android app

### Prerequisites (one-time)

Install on your local machine (not the Codespace — Android SDK needs ~10GB):

1. **Java 17 or 21** (NOT 25 — Gradle 8.2 doesn't support it)
   - macOS: `brew install openjdk@17`
   - Or download from https://adoptium.net/

2. **Android Studio** — https://developer.android.com/studio
   - During first run, let it install: Android SDK Platform 34, Build-Tools, Platform-Tools.
   - Settings → Build, Execution, Deployment → Build Tools → Gradle → Gradle JDK: 17 or 21.

3. **Enable Developer Mode + USB Debugging on your phone**
   - Settings → About phone → tap "Build number" 7 times.
   - Settings → Developer options → USB debugging: ON.

### Build & install

Clone the repo to your local machine, then:

```bash
npm install
# edit public/config.js with your Worker URL (see Part 2)
npx cap sync android
```

#### Option A — Android Studio (recommended)

```bash
npx cap open android
```

- Wait for Gradle sync to finish (first time: several minutes).
- Plug in your phone via USB. Accept the debugging prompt on the phone.
- Top toolbar: select your device, then click ▶ Run.
- The app installs and launches.

#### Option B — Command line

```bash
cd android
./gradlew assembleDebug                 # builds the APK
./gradlew installDebug                  # installs on connected device
```

APK output: `android/app/build/outputs/apk/debug/app-debug.apk`

You can also copy that APK to your phone manually and tap to install
(enable "Install unknown apps" for your file manager).

## Part 4 — First-run checks on device

When the app launches:
- It should show your existing onboarding/home screen.
- Start a call. The first time it tries to listen, Android prompts for **mic permission** — tap Allow.
- If you see "Permission denied" in the UI, go to Android Settings → Apps → Callingo → Permissions → Microphone → Allow.

**If voice doesn't work:** check that Google's speech recognition service is installed and enabled (Settings → Apps → "Speech Recognition & Synthesis from Google" → enabled). On stock Android this is preinstalled.

**If API calls fail:** open `chrome://inspect` on a desktop Chrome with the phone plugged in via USB — you can debug the WebView console live. Check that `API` is set to your Worker URL and that the Worker returns 200.

## Iteration loop

Editing the web app and seeing the change on device:

```bash
# 1. edit files in public/
# 2. sync into android/
npx cap sync android
# 3. rebuild + reinstall
cd android && ./gradlew installDebug
```

For fast iteration during dev, you can also point Capacitor at a live web server
(e.g. `npm run dev` on your laptop) by adding a `server.url` field to
`capacitor.config.json` — but the simple sync loop above is fine to start.

## Layout reference

```
cloudflare/         # Worker code (replaces netlify/functions)
  worker.js
  wrangler.toml
  README.md

public/             # the web app — single source of truth
  config.js         # runtime config: API URL
  index.html

android/            # generated by `npx cap add android` — usually don't edit
capacitor.config.json
package.json
```
